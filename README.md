# js-algorithms

> LJS 的 JavaScript 算法学习仓库 —— 练习代码、检测答卷、教案与进度档案的唯一落点。
>
> 由 **JS算法学习专家团** 维护：学习者手写代码，工程组负责搬运与版本管理。

远端仓库：`https://github.com/molunanli/js-algorithms.git`（默认分支 `main`）

---

## 一、目录规范（唯一标准）

```
js-algorithms/
├── README.md                          # 仓库说明与学习导航（本文件）
├── exercises/                         # 练习代码（唯一落点，用户手写）
│   └── {模块编号-模块名}/
│       └── {YYYY-MM-DD}-{题目slug}.js
├── quizzes/                           # 检测答卷
│   ├── {YYYY-MM-DD}-quiz.md           # 每日检测卷
│   ├── {YYYY-MM-DD}-review-{模块}.md   # 错题复盘卷
│   └── {YYYY-MM-DD}-drill-{模块}.md    # 强化训练题单
├── lessons/                           # 教案
│   ├── {YYYY-MM-DD}-{主题}.md          # 教案源稿
│   └── {YYYY-MM-DD}-{主题}.pptx        # 教案 PPT
└── progress/                          # 进度档案
    ├── progress.json
    └── daily/{YYYY-MM-DD}.md           # 学习日报
```

### 命名规则

| 类型 | 规则 | 示例 |
|------|------|------|
| 模块目录 | `{编号}-{模块中文名}` | `M13-动态规划` |
| 练习文件 | `{YYYY-MM-DD}-{题目slug}.js` | `2026-09-21-climb-stairs.js` |
| 题目 slug | 全小写、单词间用连字符 | `two-sum`、`climb-stairs` |
| 答卷 | `{日期}-quiz.md` / `-review-{模块}` / `-drill-{模块}` | `2026-09-21-drill-M13.md` |
| 教案 | `{日期}-{主题}.md` 与同名 `.pptx` | `2026-09-21-动态规划入门.pptx` |

> 模块编号与名称以《算法知识大纲》为准，不得自创别名。

### 练习文件头部模板

新建练习文件时必须写入：

```js
/**
 * @module    M13-动态规划
 * @problem   爬楼梯
 * @date      2026-09-21
 * @complexity 时间 O(n) / 空间 O(1)
 * @note      滚动变量替代数组，dp[n] 只依赖前两项
 */
```

## 二、学习导航（M01–M15 模块一览）

学习路径分四层，建议自上而下推进；M14、M15 可穿插进行，不占主线进度。

| 层级 | 模块 | 名称 | 前置 |
|------|------|------|------|
| 基础层 | **M01** | 复杂度分析 | 无 |
| 基础层 | **M02** | 数组与字符串 | M01 |
| 基础层 | **M03** | 双指针与滑动窗口 | M02 |
| 基础层 | **M04** | 哈希表 | M02 |
| 结构层 | **M05** | 栈与队列 | M02 |
| 结构层 | **M06** | 链表 | M02 |
| 方法层 | **M07** | 递归与回溯 | M01、M06 |
| 方法层 | **M08** | 排序与二分查找 | M02 |
| 结构层 | **M09** | 树与二叉树 | M06、M07 |
| 结构层 | **M10** | 堆与优先队列 | M09 |
| 结构层 | **M11** | 图与遍历 | M05、M09 |
| 方法层 | **M12** | 贪心 | M08 |
| 方法层 | **M13** | 动态规划 | M07、M12 |
| 精进层 | **M14** | 位运算 | M01 |
| 精进层 | **M15** | JS 语言陷阱与工程实践 | M02 |

### 掌握度分级（L0–L4）

| 等级 | 含义 |
|------|------|
| L0 | 未接触 |
| L1 | 能识别 |
| L2 | 能复现 |
| L3 | 能独立（**晋级门槛**） |
| L4 | 能迁移 |

- 连续 2 次测评达 L3 及以上才允许推进下一模块。
- 等级判定遵循「**证据先行**」：无答卷或练习代码证据，不得写入等级。

## 四、工程纪律

- 管家只做**搬运与版本管理**，不修改学习者代码内容。
- 禁止 `git reset --hard`、`git checkout -- .`、`git clean -fd`、`git push --force` 等破坏性操作。
- 遇到冲突保留双方改动并报告，不擅自取舍。
- 每次学习闭环完成后即时提交推送，不留跨日未提交变更。
- `push` 失败时明确记录「已本地提交但未推送」，不得谎报成功。

### Q2　【M01 复杂度分析 ｜ 复杂度分析（须写推导）｜ 11 分 ｜ 建议用时 ≤10 min】

阅读下面的 JavaScript 代码。**约定：`n` 表示二维数组 `rows` 中元素的总个数**（即 `rows` 所有行长度之和）。

```js
function flattenSum(rows) {
  let total = 0;
  for (let i = 0; i < rows.length; i++) {
    const row = rows[i];
    for (let j = 0; j < row.length; j++) {
      total += row[j];
    }
  }
  return total;
}
```

请写出 `flattenSum` 的**时间复杂度**与**空间复杂度**，并**逐步说明推导过程**。

## Q2 参考答案与判分点（11 分）

**参考答案**

- **时间复杂度：O(n)**（n 为 `rows` 中元素总个数）。
  推导：外层循环执行 `rows.length` 次；对第 i 行，内层循环执行 `Lᵢ = rows[i].length` 次。内层循环的执行总次数 = Σᵢ Lᵢ = n。故 `total += row[j]` 共执行 n 次，总体为 O(n)。
  **关键点**：不能仅凭"两层嵌套循环"就判为 O(n²)——必须数实际迭代次数。此处内层总迭代数等于元素总数，与行数无关。
  （若按"行数 R、最长行长 L"表述，则为 O(R·L)；只有当每行长度都与 R 同阶时，O(R·L) 才退化为 O(n²)，本题不满足该前提。）
- **空间复杂度：O(1)**。
  推导：仅使用常数个变量（`total`、`i`、`row`、`j`）；`const row = rows[i]` 只是对已有行数组的**引用**，不产生元素级拷贝；无递归调用，无递归栈开销。

| 判分点 | 得分 |
|--------|------|
| 时间结论正确（O(n)） | 2 |
| 时间推导完整：数出内层总迭代 = 元素总数、指出不能只看循环层数 | 4 |
| 空间结论正确（O(1)） | 2 |
| 空间推导完整：常数变量 + 引用非拷贝 + 无递归栈 | 3 |
| **合计** | **11** |

  // 1) 沿主对角线转置
  for (let i = 0; i < n; i++) {
    for (let j = i + 1; j < n; j++) {

      matrix[i][j] = matrix[j][i];
      matrix[j][i] = t;

}

## Q10 参考答案与判分点（6 分）

**10a 参考答案（二分，O(log n)）**

```js
function searchInsert(nums, target) {
  let lo = 0, hi = nums.length; // 左闭右开
  while (lo < hi) {
    const mid = (lo + hi) >> 1;
    if (nums[mid] < target) lo = mid + 1;
    else hi = mid;
  }
  return lo;
}
```

- 示例用例（题面已给）：`[1,3,5,6], 5` → `2`；`[1,3,5,6], 2` → `1`
- **隐藏边界（用于 L3 判定）**：空数组 `[], 5` → `0`；`target` 小于所有 `[2,3], 1` → `0`；`target` 大于所有 `[2,3], 9` → `2`。

| 判分点 | 得分 |
|--------|------|
| 二分框架边界安全（`mid` 与 `lo/hi` 更新匹配、不死循环）+ 题面示例通过 | 4 |
| 10b：边界 ≥ 3 组（空数组 / 首端插入 / 尾端插入）且写出「输入 → 期望输出」 | 2 |

- 常见失分：`hi = nums.length - 1` 与左闭右开混用导致死循环；空数组返回 `-1`（应为 `0`）。

**11a 参考答案（O(n) / O(1)）**

```js
function climbStairs(n) {
  if (n <= 2) return n;            // n=1 -> 1, n=2 -> 2
  let a = 1, b = 2;                // a = f(i-2), b = f(i-1)
  for (let i = 3; i <= n; i++) {
    const c = a + b;
    a = b;
    b = c;
  }
  return b;
}
```

- 示例用例（题面已给）：`3` → `3`；`5` → `8`
- **隐藏边界（用于 L3 判定）**：`n = 1` → `1`；`n = 2` → `2`。

| 判分点 | 得分 |
|--------|------|
| 状态转移正确（`f(n) = f(n-1) + f(n-2)`）+ 题面示例通过 | 6 |
| 11b：正确说明 `f(1)=1`、`f(2)=2` 初始化，并说明空间 O(1)（只保留前两项滚动变量） | 2 |

- 复杂度不达标（用长度 n 的数组 → 空间 O(n)）→ 扣「空间 O(1)」相关分。
- 常见失分：`f(2)` 初始化写成 `1`；用数组自底向上（可对但空间非 O(1)）；`n=1` 未处理。
